# CompTIA SecAI+ (CY0-001) Practice Exam

An unofficial, self-contained mock exam for the CompTIA SecAI+ (CY0-001) certification. Open [`practice-tests/secai-plus-practice-test.html`](practice-tests/secai-plus-practice-test.html) directly in any browser — no server or build step required.

## What it does

- **6 independent practice tests**, each with 60 different, original questions — pick one from the start screen.
- Scenario-driven, exam-style questions (BEST/MOST/FIRST-style qualifiers, closely related distractors) rather than simple keyword matching, matching the real exam's format (single-answer multiple choice, multiple-response, and a scenario/sequencing item).
- **60 questions in 60 minutes**, with a live countdown timer that auto-submits when time runs out — and a **Pause** button that freezes the timer and covers the question until you're ready to resume.
- **Domain weighting matches the official blueprint exactly, on every one of the 6 tests:**
  | Domain | Weight | Questions on this exam |
  |---|---|---|
  | 1.0 Basic AI Concepts Related to Cybersecurity | 17% | 10 |
  | 2.0 Securing AI Systems | 40% | 24 |
  | 3.0 AI-Assisted Security | 24% | 15 |
  | 4.0 AI Governance, Risk & Compliance | 19% | 11 |
- Question and answer-option order are shuffled on every attempt.
- A question palette lets you jump between questions and flag items for review, just like the real testing interface.
- On submission you get a scaled score (100–900 scale, 600 to pass), a per-domain performance breakdown, and a full answer review with explanations.

This is a study aid with original practice questions modeled on the published exam objectives and weighting — it is not affiliated with, endorsed by, or sourced from CompTIA, and does not reproduce any actual exam content.
